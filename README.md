# ShiftCal Web

광고·로그인·외부 서버 없이 개인용으로 사용하는 교대근무 PWA 초안.

## 현재 구현
- ShiftCal Swift 원본의 주요 패턴 9개
- 기준일·기준 근무 설정
- 패턴별 근무 유형의 시작·종료 시각 설정(종료 시각이 이르면 다음 날 근무)
- 월간·주간·목록 일정 보기(선택한 보기 방식은 브라우저에 저장)
- 근무와 메모를 함께 보여 주는 컴팩트한 오늘 일정 요약
- 날짜별 근무 예외 지정(당직·비번·연가·공가)
- 저장된 사용자 근무 목록(한 번 만든 근무를 재사용)
- 사용자 근무별 색상 선택
- 날짜별 메모(최대 500자)
- 메모 목록 화면
- 월별 근무 통계·기본근무시간·시간외시간·야간근무시간·휴일근무일수·메모 개수
- 수당 계산에서 제외할 식사·수면·휴식시간 설정
- 대한민국 공휴일·대체공휴일·선거일 표시
- 주요 기념일 표시(어버이날·스승의날·국군의날 등)
- 아이폰 모바일용 bottom sheet 입력창
- 화면 하단에 고정된 달력·메모·통계·설정 메뉴
- 제목과 장식을 줄이고 달력 사용 면적을 넓힌 모바일 중심 화면
- 월간 달력 칸과 주간·목록 행에 메모 내용 미리보기
- 근무 변경 표시
- localStorage 저장
- 검증된 JSON 백업 내보내기·가져오기
- 홈 화면용 아이콘을 포함한 PWA manifest/service worker

## 실행
```sh
python3 -m http.server 4173
```
브라우저에서 `http://localhost:4173` 접속.
아이폰에서는 HTTPS로 배포한 뒤 Safari의 공유 메뉴에서 “홈 화면에 추가”를 사용한다.

## 초과수당 예상 기준

- 현업·교대근무자를 전제로 `수당용 실근무시간 - 기본근무시간 - (휴일근무일수 × 8시간)`으로 시간외근무시간을 예상한다.
- 기본근무시간은 월요일부터 금요일 중 관공서 공휴일을 제외한 날에 8시간씩 계산한다. 날짜에 연가·공가·병가·특별휴가를 지정하면 앱의 계산 규칙에 따라 요일과 관계없이 기본근무시간에서 8시간을 제외한다.
- 야간근무시간은 22:00부터 다음 날 06:00까지의 실제 근무 구간으로 계산한다.
- 휴일근무는 토요일 또는 관공서 공휴일에 09:00부터 18:00까지 전체를 근무한 경우 1일로 계산한다. 일부 시간만 근무한 경우에는 휴일근무 1일로 바꾸지 않는다.
- 식사·수면·휴식시간은 기관별 인정 방식이 달라 설정값을 근무 1회마다 공제한다.
- 휴게가 발생한 정확한 시간대는 근무표만으로 알 수 없어 야간근무시간에서는 자동 공제하지 않는다.
- 시간외근무 월 합계의 1시간 미만은 절사한다.
- 변동 공휴일은 공식 월력요항을 기준으로 2026년과 2027년 데이터를 제공한다. 그 밖의 연도는 통계 화면에 확인 안내를 표시한다.

이 값은 근무표만으로 계산한 예상치다. 실제 지급은 초과근무명령·승인, 기관 예산, 휴일근무 후 대체휴무, 기관별 휴게시간 인정 여부에 따라 달라질 수 있다. 기준은 [공무원수당 등에 관한 규정](https://www.law.go.kr/법령/공무원수당등에관한규정), 인사혁신처의 [공무원보수 등의 업무지침](https://www.mpm.go.kr/mpm/info/resultPay/payBoard/?boardId=bbs_0000000000000035&category=%EB%B3%B4%EC%88%98&mode=list), 우주항공청의 [2027년 월력요항](https://www.kasa.go.kr/prog/plcyBrf/brief/kor/sub01_01_04/view.do?plcyBrfNo=431)을 따른다.

## 개발 품질 자동화
- `AGENTS.md`에 ShiftCalWeb 작업 규칙·필수 검증 절차를 기록한다.
- `main` push와 pull request마다 GitHub Actions가 문법 검사와 전체 계약 테스트를 실행한다.
- Pages 배포는 `.github/workflows/pages.yml`이 담당한다.
